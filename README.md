# 모닝 마인드 (Morning Mind) 🌅
> 아침 명상 음악 큐레이션 & 데일리 마음가짐 저널링 웹 앱

---

## 🌟 주요 기능
1. **아침 명상 음악 플레이어 (YouTube 연동)**
   * 엄선된 4가지 아침 명상 트랙 프리셋 (새벽 숲속 피아노, 긍정 에너지 로파이, 528Hz 싱잉볼, 어쿠스틱 기타)
   * 본인이 원하는 유튜브 음악 영상 링크 직접 입력 및 재생 지원
   * 5분 / 10분 / 15분 명상 카운트다운 타이머 & 종료 알림 벨

2. **오늘의 마음가짐 글귀 (Daily Inspiration)**
   * 하루를 활기차고 긍정적으로 시작하게 돕는 영감 글귀 큐레이션
   * 글귀 새로고침 및 **'오늘의 글귀 인용하기'** 원클릭 복사

3. **마음가짐 기록 (Morning Journaling)**
   * 오늘의 기분/마음 상태(Mood) 5단계 선택
   * 오늘 하루의 한 줄 확언 / 다짐 (Today's Affirmation)
   * 감사한 일 3가지 (Three Gratitudes)
   * 명상 후 깊은 생각 및 성찰 기록 (Reflection Editor)
   * 저장 시 축하 애니메이션(Confetti) 효과 및 로컬 브라우저 영구 보관

4. **기록 보관소 & 검색 (History & Archive)**
   * 날짜별 기록 모아보기 및 상세 팝업 모달
   * 키워드 실시간 검색 (다짐, 감사, 성찰 내용 통합 검색)
   * 날짜 필터링 (특정 날짜 기록 바로 찾기)
   * 데이터 JSON 백업 내보내기 및 복원(가져오기) 기능

5. **디자인 & 편의성**
   * 반응형 모바일/데스크톱 UI (Tailwind CSS, Lucide Icons)
   * 눈이 편안한 라이트 / 다크 모드 토글

---

## 🚀 실행 방법
별도의 빌드나 서버 설치 없이, `index.html` 파일을 크롬이나 엣지 등 웹 브라우저로 더블 클릭하여 바로 열어 사용할 수 있습니다.
